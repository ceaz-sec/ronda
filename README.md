# RONDA
**Purpose**: The word Ronda means to patrol, it is the act of watching or guarding by patrolling. That is the purpose of this repo specifically for software supply chain artifacts. Ronda is a process of triaging containers/images before intake into in aenvironment. Ronda focues on tiaging widely used and relied on open source images.


## ROADMAP
- Pipeline of tested open source container images, spanning servers, apps, databases and more.

- Reports of findings from Ronda triage efforts.

- Scripts and repertable workflow diagrams.
